# OS2 (V7) — Engineering Notes: Axio Observer benchmark → OS2 hardware

**Дата:** 2026-10-19
**Мастер-анализ:** `ARGUS-OS1/docs/AXIO_OBSERVER_ENGINEERING_ANALYSIS_2026-10-19.md`
**Все PMID верифицированы 2026-10-19.**

OS2 (V7) — коммерчески-уровневый этап ARGUS (60×/1.2 WI + sCMOS + microfluidic + Jetson AGX, N=100 эмбрионов). Это этап, где уроки Zeiss Axio Observer 7 наиболее применимы: именно здесь требуется **аппаратное удержание фокуса, среда и чувствительная детекция** для многочасовых/многодневных серий.

## 1. Что берём из Axio Observer 7 для OS2

| # | Решение OS2 | Источник | Обоснование |
|:-:|-------------|----------|-------------|
| 1 | **Аппаратный автофокус/удержание фокуса** | Definite Focus 3 / Nikon PFS / Olympus TruFocus ZDC / Leica AFC | Главный режим отказа multi-day съёмки — термический/механический дрейф Z. Для N=100 эмбрионов с интервалом 2 мин обязателен автоматический фокус без вмешательства. Открытая реализация: fiducial autofocus (PMID 42274973), LED-автофокус (PMID 42525498). |
| 2 | **Инкубационный модуль** (CO₂/температура/влажность) | Axio Observer live (Glass Lid CO₂/O₂ heated, Temperature Controller, Heated Plate K) | C. elegans эмбрионы развиваются 3 ч при 25 °C; клеточные линии (hPSC-CM, RPE1) требуют 37 °C/5% CO₂. Без среды — невоспроизводимость и артефакты физиологии. Оценка бюджета: stage-top модуль ~$3–6K или инкубатор-камера. |
| 3 | **Мультиканальный LED-движок** (≥5 каналов) | Colibri 7 (7 каналов) / Lumencor Aura | Низкая фототоксичность + быстрые переключения между 7 маркерами (SAS-4::GFP, SAS-1::mCherry, Centrin1::BFP, Dendra2, PAR-2::GFP, PAR-3::mCherry, CED-3::mCherry, Histone::CFP). |
| 4 | **Piezo Z + sCMOS** | Scanning Stage PIEZO + pco.edge 4.2 | Центриольные Z-стеки (глубина 1–2 мкм, шаг 100–300 нм) требуют нано-точного Z и высокочувствительного sCMOS (QE>90%, 16-bit). |
| 5 | **Автоиммерсия** | Autoimmersion module | 60×/1.2 WI на длинных сериях — стабильность иммерсии без рук (до V9). |
| 6 | **Оптическое сечение (SIM/HiLo-класс)** | Apotome 3 | Для 3D-контраста центриолей в рассеивающих образцах; дешевле конфокала. |
| 7 | **Micro-Manager + Mastodon** | ZEN / Mastodon (PMID 42841415) | Единый конвейер lineage: acquisition → сегментация → трекинг → pedigree. |

## 2. Слабые места эталона, которые OS2 обходит

| Слабое место Axio Observer | Как обходит OS2 |
|---------------------------|-----------------|
| Цена $100–200K+ | OS2 ~$126K (но с локальным edge-AI, без сервис-контрактов) |
| Закрытый ZEN/автофокус | Открытые драйверы, Micro-Manager, ремонтопригодность |
| Фототоксичность (даже brightfield — PMID 42393487) | Body Law: phototoxicity ceiling; LED-минимизация; сенсорные камеры |
| Нет автономной смены образцов | V9-Standard (2 руки) |

## 3. Бюджетные заметки (влияние на ~$126K)

- Инкубационный модуль: **+$3–6K** (не входил в исходную смету — добавить).
- Аппаратный автофокус (открытая реализация): **+$0.2–1K** (фидуциальные маркеры + LED; либо удержание через piezo).
- Мультиканальный LED-движок: **+$2–5K** (уже частично покрыт лазерами 405/488/561/640 — сверить: для live-cell предпочтителен LED с низкой фототоксичностью, не только лазер).
- Piezo Z: **+$3–8K**.

> Итог: добавление инкубации + автофокуса + LED повышает надёжность N=100-эксперимента, который иначе рискует «потерять фокус/физиологию» на длинных сериях. Экономически обосновано: цена провала серии (100 эмбрионов, месяцы) ≫ цена модулей.
